#+title: mysql

[[https://melpa.org/#/mysql][file:https://melpa.org/packages/mysql-badge.svg]]

A pure Emacs Lisp MySQL wire protocol client.  It speaks the
classic MySQL protocol directly and does not shell out to the =mysql= CLI.

* Features

- TLS connections
- Authentication with =mysql_native_password= and =caching_sha2_password=;
  other server plugins such as =sha256_password= are reported as unsupported
- Prepared statements
- Server-side prepared statement cursors with =mysql-execute-cursor= and =mysql-fetch=
- Transactions
- Public transaction helpers: =mysql-autocommit-p=, =mysql-in-transaction-p=,
  =mysql-set-autocommit=, =mysql-commit=, and =mysql-rollback=
- Public connection state helpers: =mysql-live-p=, =mysql-busy-p=,
  =mysql-connection-id=, =mysql-current-database=, and =mysql-select-database=
- Public response drain helper for clients that cancel a running query out of
  band: =mysql-drain-query-response=
- Percent-decoded =mysql://= connection URIs through =mysql-connect-uri=
- Support for MySQL 5.6+, MySQL 8.x, and MariaDB 10.11

* Usage

#+begin_src emacs-lisp
(require 'mysql)

(let ((conn (mysql-connect :host "127.0.0.1"
                           :port 3306
                           :user "root"
                           :password "secret"
                           :database "mydb")))
  (unwind-protect
      (let ((result (mysql-query conn "SELECT 1 AS n")))
        (message "Rows: %S" (mysql-result-rows result)))
    (mysql-disconnect conn)))
#+end_src

Transaction helpers are available when you want explicit control over the
session state:

=mysql-in-transaction-p= and =mysql-autocommit-p= track server status from completed text and prepared query results as well as OK responses. In particular, a result-set query that opens a transaction in manual mode is visible to callers without issuing another query.

#+begin_src emacs-lisp
(mysql-set-autocommit conn nil)
(unwind-protect
    (progn
      (mysql-query conn "INSERT INTO demo(name) VALUES ('alice')")
      (mysql-commit conn))
  (mysql-set-autocommit conn t))
#+end_src

* Timeout recovery

When a query times out before its first response packet is complete, the
connection rejects new commands until =mysql-drain-query-response= consumes the
pending response.  If a timeout happens after result parsing has started, the
connection is closed because the generic drain API cannot safely reconstruct
the partially consumed result set.

Version 0.2.4 validates every packet sequence and bounds logical messages and
command responses with =mysql-max-message-bytes= and
=mysql-max-response-bytes=.  Authentication packets now fail closed, and
prepared binary rows honor column signedness and decode text, JSON, DECIMAL,
BIT, and binary values from full column metadata.

Prepared integer parameters preserve the full signed and unsigned 64-bit range. Values outside that combined range raise =mysql-stmt-error= before transmission. Quitting or otherwise abandoning authentication releases the partially established connection and its process buffer.

* Installation

Install =mysql= from MELPA:

#+begin_src emacs-lisp
(package-install 'mysql)
#+end_src
